# KeyFrame

KeyFrame is a 2D vector-style rhythm game inspired by piano simulators.
Notes fall along lanes toward a hit line, and the player presses the
matching key in time with the music. Each correct hit plays the note's
sound, so the player is effectively performing the song.

## Features
- Falling-note gameplay with hit timing (Perfect / Great / Good / Miss)
- Score, combo, and accuracy tracking
- Main menu, in-game HUD, and result screen
- Object-oriented design (GameObject, Pemain, Not)
- Platforms: PC and Mobile

## Controls
- PC: D / F / J / K (or the on-screen piano keys)
- Mobile: tap the lanes or keys on screen

## Goal
Finish each song with the highest score, longest combo, and best accuracy
you can.
